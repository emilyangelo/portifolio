## 📌 Sobre o Projeto

Plataforma Web interativa desenvolvida com estética **Terminal / Telemetria CLI**, criada para apresentar meu perfil profissional, competências técnicas, histórico prático e laboratórios em **Infraestrutura de TI, Redes, IAM e Segurança da Informação**.

### 🔗 Link de Acesso Público
> 🚀 **Acesse o ambiente em produção:** [https://portifolioemilyangelo.web.app/](https://portifolioemilyangelo.web.app/)

---

## ⚡ Recursos & Funcionalidades

- **Interface Terminal CLI:** Layout inspirado em interfaces de linha de comando com simulador de logs de sistema em tempo real.
- **Painel de Telemetria:** Apresentação dinâmica da pilha técnica e camadas de protocolo.
- **Mapeamento de Competências:** Estruturação visual de tecnologias em Suporte, Redes, IAM, Linux/Windows Server e Automação.
- **Labs & Projetos:** Seção dedicada para demonstrar laboratórios práticos e documentações técnicas.
- **Canais de Conectividade:** Links diretos para contato via e-mail e redes profissionais.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Deploy & Hospedagem:** Firebase Hosting
- **Design System:** Custom CSS (Estilo Dark / Terminal / Neon Cyberpunk)
- **Ícones & Badges:** Font Awesome / Shields.io
